# 临时任务记忆

> 目的：在长任务发生 context compaction 后恢复完整范围。任务完成前保留此文件。

## 任务目标

完全重构当前目录里的 `worker.js` Cloudflare Worker 在线剪贴板程序。不是在原有基础上修改，而是使用现代、模块化、高性能、高速度、高标准的代码框架完全重建现有的过时实现。

## 新增功能

1. **ip-trace 调试端点**：读取同目录的 `aioapi.js`，将其根目录 CF IP trace 功能复刻到本项目 `/ip-trace` 端点，显示访问者基本信息。
2. **可编辑**：paste 创建后可选择只读模式（默认）、编辑模式、Markdown 编辑模式和编辑历史查看。编辑模式中文本框可修改内容，修改后 1 秒防抖自动上传保存；使用等宽代码字体，可用嵌入编辑器。
3. **Markdown WYSIWYG 编辑和预览**：增加 Markdown 编辑模式，用现代框架嵌入 WYSIWYG Markdown 编辑器，以 Markdown 源码格式解析 paste 内容并在网页内编辑。增加 `/md/xxxxxx` 只读 Markdown 预览端点，用 Markdown 转 HTML 框架渲染，区别于接收 HTML 源码的 `/html/xxxxxx`。
4. **编辑历史**：编辑历史存入同一个 KV namespace 的共生 metadata 条目，只保留最近 3 次，以 GitHub 风格渲染查看。
5. **密码**：创建或修改时可设置、修改、清除密码，存储于共生 metadata 条目。查看、编辑、删除加密 paste 时只需在打开链接时输入一次密码；密码存在浏览器内存，后续请求附带。密码按要求明文传输。所有网页形式、多格式、`/md`、`/raw`、`/html`、API 和 MCP 都必须验证密码，错误时返回 403。获得链接和密码后即可完全控制 paste，不增加账户或其他鉴权。
6. **阅后删除**：创建时可设置并存入共生 metadata 条目，可与密码同时使用。创建成功后不自动打开 paste。第一次成功打开任意形式（网页、API、MCP、raw、html、md、file 等）后删除主数据和共生 metadata。网页端禁止编辑、历史等操作，仍提供 raw 和多格式导出；打开其中任一种即消费并删除。密码失败不能消费。
7. **自定义链接**：创建时允许指定存储 URL key；后端拒绝已有 key 和所有内部路由端点。编辑时不能改 key。
8. **永久保存**：`永久` 是合法有效期，不设置 KV expiration。
9. **修改失效时间**：编辑时可修改有效期。
10. **MCP**：`/mcp` 提供兼容 MCP 的服务器，包含增删改查、历史、密码、阅后删除、有效期设置等网页端大部分文本功能；不提供 WYSIWYG 等不适合大模型的功能。

## 改进和兼容

- 完整重建过时代码，修复功能、性能、结构问题；完全重构不受最小修复原则限制，但实现仍避免无用途代码和依赖。
- 不增加多余鉴权、限流等安全步骤。网页、curl 或 MCP 只需链接和密码（如有）即可完全控制 paste。
- 复刻旧功能：Web UI、`/api`、raw、html、file 等多格式链接、有效期、标题、拖放文件、复制、换行、删除等。
- 前端使用现代框架合理适配和美化，但不能太重；新增功能要有对应按钮和表单。

## 数据结构约束

- 主 paste 继续以 `key -> 明文内容` 存储于原 KV namespace。
- 编辑历史、密码、阅后删除等 metadata 存储在同一 namespace 的外挂共生条目。
- 主条目和共生条目设置相同 expiration。

## 开发流程

- 全面阅读当前代码、`aioapi.js`、外部资料、Context7、Cloudflare API 限制和外部开源代码；寻找适用框架和依赖，避免重复造轮子，可采用 Vercel 等前后端框架。
- 使用 Superpowers 技能套件和 TDD。先写 spec，再写详细实施计划，然后连续完成全部新增功能、修复和性能优化。
- 最后执行 verification，逐项核对，无遗漏。
- 测试使用 Wrangler，必须执行 Wrangler 本地调用 smoke test。
- review 和 plan 使用 Opus 1M xhigh；编码执行使用 Sonnet 1M xhigh。
- 若子代理或 workflow 因 API 问题终止，恢复其进度；若连续 3 次以上遇到 context 过大或 autocompact，改用 `claude -p` 调用带 `[1m]` 的模型，在 worktree 运行后台任务。
